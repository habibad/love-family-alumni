## Content safety

Until approved member data and visibility policy are available, display visibly marked demo placeholders only; e.g. 'Alumni Profile Preview', 'Batch pending', anonymized silhouette/initial badge. Do not expose private emails, phone numbers, donations, dues, location, or alumni IDs.
